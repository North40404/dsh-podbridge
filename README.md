# dsh-podbridge

> 本文件是**仓库门面**：这个项目是什么、怎么组织。插件安装与配置细节见 [`plugin/README.md`](plugin/README.md)。


Pod App 与 DSH 会话之间的桥接：把聊天消息投进会话，把回复推回聊天软件。

## 它做什么

```
手机/桌面客户端 ──HTTP──► 桥接 ──投递──► DSH 会话
                            ◄──推送──
```

- **下行**：SSE（`GET /events?since=&token=`），服务端主动推 `msg`
- **上行**：`POST /send`、`POST /upload`、`GET /history`
- **聚合**：同一波消息在静默窗口内合并成一次投递，避免模型被逐条打断
- **文件**：上传落到磁盘，客户端按 id 取回；协议里定义了消息的 `attachments`

## 与"触发类"插件的边界

**本插件拥有消息路径（收消息、决定回不回），触发类插件拥有触发路径（什么时候叫醒模型）。**

两者互不知道对方。它们做的事其实一样——"往会话里投一条消息"——
所以停用任何一个，另一个照常工作。

## 协议要点

- 通道：**SSE 下行 + POST 上行**（不是 WebSocket；早期试过，本地 link 安装解析不到 `ws`）
- 鉴权：一次性配对码换长期 token；`/events`、`/send`、`/files` 都要 token
- `seq` 由服务端分配、单调递增，**客户端不得自造**
- 附件**不强制**服务端长期保留，但客户端会依赖 `/files/<id>` 作为本地副本丢失后的退路

## 警告

这套东西会把一个会话**暴露到网络**。部署时至少要：

- 桥接自己跑在 `127.0.0.1`，用 frp / SSH 反向隧道 / Tailscale 之类把外部端口转进来
- 配对码不要外传；token 泄露等于对方能读你所有聊天记录
- 别把 8787 直接映射到公网裸奔（虽然有 token，但没有 TLS）

## 发文件：两条路（务必读完）

本插件提供两种把本地文件推到客户端的方式。两者共用同一份白名单与大小上限实现
（`deliverLocalFile()`），区别只在"谁能调用"。

| 路径 | 给谁用 | 为什么需要它 |
|---|---|---|
| 工具 `pod_send_file` | 模型在对话里发文件 | 自然、不需要 shell |
| `POST /api/dsh-podbridge/send-file` | 脚本、定时任务、**看不到工具的会话** | 工具可见性在 agent 创建时固定，见下 |

### 工具 `pod_send_file` 的注意事项

1. **可见性在 agent 创建时固定**：插件注册之后**新建**的会话才有这个工具；
   已经存在的会话看不到它，也不会因为插件重载而补上。这是 DSH 的语义，不是插件的 bug。
2. **注册为全局**（不设 `when`）：所有新会话都看得到，但 `execute` 里会校验
   `agent.id === settings.sessionId`，非绑定会话调用会得到明确报错（而不是静默消失）。
3. **不要设 `deferLoading: true`**：延迟加载的工具不会出现在模型当轮的 schema 里，等于不可达。
4. **路径白名单**：默认允许绑定会话的 cwd、下载目录、插件自己的文件目录；
   开关是设置页的「文件白名单」，**由人操作，模型改不了**。
5. 超过 `maxBytes` 会直接拒绝。

### HTTP 端点的注意事项

1. **它挂在 DSH 的 web 端口上，不是桥接的 8787**。
   8787 只有数据面：`/health`、`/events`、`/send`、`/upload`、`/files/<id>`。
   打到 8787 会 404。
2. **没有鉴权**，和所有 `/api/dsh-podbridge/*` 管理端点一样，靠的是「DSH web 只监听 127.0.0.1」。
   **不要把这个端口暴露到公网。** 需要外网访问时，暴露的应当只有 8787（数据面，有 token）。
3. 请求体：`{"path": "<绝对路径>", "caption": "可选说明"}`；
   成功返回 `{ok,name,size,mime,id}`，失败返回 400 + `{ok:false,error}`。
4. **它不属于 Pod 协议**：协议 v1 没有定义"服务端主动推送文件"，所以换一个桥接实现就没有这个端点。
   它属于本插件的便利设施。
